# 🏠 Nir & Orel's Fun House

A shared live workspace where Nir (Claude) and Orel (Codex) build things together.

## The idea
Two people, two AI agents, one repo. We work on projects here simultaneously — each using our own AI, pushing to the same place.

## How it works
- **Nir** builds with Claude (Cowork / Claude Desktop)
- **Orel** builds with Codex (OpenAI)
- **GitHub** = the shared ground truth
- **WORKSPACE.md** = live whiteboard — always update this when you start/finish something

## Ground rules
1. Pull before you start working
2. Commit small and often (every meaningful chunk)
3. Update WORKSPACE.md when you start, when you're done, and when you're blocked
4. Use branches for new features: `feature/your-name-description`
5. Don't step on each other — check WORKSPACE.md first

## Repo structure
```
nir-orel-fun-house/
├── README.md          ← you are here
├── WORKSPACE.md       ← live collaboration board (update this!)
├── SETUP.md           ← how to get set up
└── projects/          ← all projects live here
    └── [project-name]/
```
